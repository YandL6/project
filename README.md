# LeetCode 热题 HOT 100 刷题笔记

基于 LeetCode 热题 HOT 100 题单的刷题记录与知识管理工具（纯前端，无需后端，打开即用）。

## 功能

- **题库全覆盖**：HOT 100 全部 100 题（简单 21 / 中等 66 / 困难 13），每题包含：
  - 多方法**解题思路**（含步骤拆解与时间/空间复杂度）
  - **关键难点**（编号列出易错点）
  - **知识点标签**（点击可跳转知识库对应条目）
- **知识库**：35 条知识点（STL 容器、数据结构、算法思想、技巧），含用法、复杂度与刷题提示
- **易混淆知识点**：36 组对比（如 0-1 背包 vs 完全背包、单调栈 vs 单调队列、DP vs 贪心），含代码示例与记忆口诀
- **进度追踪**：答题状态标记、难度统计、完成度进度条
- **排序与筛选**：默认按难度排序，支持题号、标题、最近添加排序，支持难度筛选与关键词搜索
- **数据本地持久化**：所有记录保存在浏览器 localStorage，可导出/导入 JSON

## 使用

直接用浏览器打开 `index.html` 即可，或部署到任意静态托管（如 GitHub Pages）。

> 数据结构说明：默认数据版本号为 `app.js` 中的 `DATA_VERSION`，更新默认数据时递增版本号，已有浏览器缓存的用户会自动加载新数据。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 样式
- `app.js` — 逻辑与全部默认数据（题目 / 知识库 / 易混淆点）
