四个方向同根同源（都吃机器学习 + 深度学习 + 工程能力这碗饭），但考察侧重、岗位密度、竞争烈度差异很大。先用一张表建立全局认知：

方向典型岗位名核心考察岗位密度竞争烈度
通用算法 机器学习算法工程师 / 算法工程师 ML 基础（LR/GBDT/SVM）、特征工程、SQL、LeetCode 中 中
大模型（LLM） 大模型算法 / 预训练·后训练研究员 / LLM Infra Transformer 细节、训练范式（SFT/RLHF/DPO）、推理优化、论文 高（2026 最热） 高

选方向的现实建议：搜广推岗位最多、变现路径最成熟，适合求稳；大模型和 Agent 是 2026 增量最大的方向，但对论文/实习/项目深度的要求更高；通用算法岗常作为前几者的"兜底"投递项。四者可同投，八股准备有约 60% 重叠（详见 八股文知识库）。

二、通用算法工程师（机器学习方向）

岗位画像 基础盘

业务场景最分散的一类：风控、量化、图像、语音、运筹优化、数据挖掘都算。面试最看重机器学习基础的扎实程度和代码能力，是其他三个方向的公共地基。对学历的容忍度相对最高，双非强项目也有机会。

核心技能（JD 高频词）

机器学习基础（LR / 决策树 / SVM / 朴素贝叶斯） 集成学习（XGBoost / LightGBM / CatBoost） Python（NumPy / Pandas / Scikit-learn） SQL（复杂取数、窗口函数） 数据结构与算法（LeetCode medium） 特征工程模型评估（AUC / KS / F1）正则化与过拟合处理 Linux 环境Spark / Flink（大数据场景）Git

加分项：Kaggle / 天池竞赛名次、ACM / ICPC 经历（虾皮等公司 JD 明确写了"有 ACM / Topcoder Algorithm 或类似算法竞赛经历者优先"）、顶会论文、高星开源项目。

学习路径

第一阶段 · 地基（1~2 个月）统计学习基础：梯度下降、正则化（L1/L2）、损失函数、偏差-方差分解；刷完 sklearn 文档里的经典模型；每天 2~3 道 LeetCode。
第二阶段 · 主力模型（1 个月）吃透 XGBoost / LightGBM：原理（ boosting / 负梯度 / 二阶泰勒）、调参、和 LR 的对比（这是最高频面试题之一）。
第三阶段 · 实战（1~2 个月）打一场完整的 Kaggle / 天池比赛（CTR 预测类最对口），走完数据清洗 → 特征工程 → 模型融合 → 线上提交全流程，这段经历能撑起简历一整页。
第四阶段 · 八股串联对照 八股文知识库 第二、三章逐题过，确保每题能讲 3 分钟以上。

三、大模型（LLM）算法

岗位画像 2026 最热

分为几条细分线：预训练（数据 / 架构 / Scaling Law）、后训练（SFT / RLHF / DPO / 推理强化）、推理与部署（量化 / KV Cache / vLLM）、多模态。以 DeepSeek 为例，其招聘页明确列出了"预训练（数据/算法）研究员""后训练（数据/算法）研究员""多模态理解研究员""大模型训练/推理框架工程师"等岗位。门槛明显偏高：多家公司 JD 要求硕士起步、博士优先（如阿丘科技大模型算法工程师要求"硕士及以上学历，1 年以上大模型或深度学习相关经验，博士优先"）。

核心技能（JD 高频词）

Transformer 全家桶（Attention / 位置编码 / 归一化） PyTorch 微调范式（SFT / LoRA / 全参微调） 对齐（RLHF / DPO / PPO） 推理优化（vLLM / 量化 / KV Cache） 分布式训练（DeepSpeed / Megatron）数据工程（清洗 / 配比 / 去重） 评测（MMLU / 人类评估）RAG / AgentTensorRT / Triton 部署CUDA（Infra 岗）

加分项：ACL / NeurIPS / ICML / ICLR 论文；复现过开源大模型训练（如 nanoGPT、DeepSeek-R1 复现笔记）；对 Long CoT 强化学习有实践（月之暗面"强化学习算法研究员（大模型）"JD 明确写了研究 Long CoT 的 RL 技术，方向一为 Reasoning、方向二为 Agent，要求 985/211 研究生以上、博士优先）；有 TensorRT / vLLM 落地经验。

学习路径

第一步 · 吃透 Transformer能手推 Scaled Dot-Product Attention 的复杂度、讲清 RoPE 为什么支持外推、Pre-Norm 与 Post-Norm 的训练稳定性差异——这是所有大模型面试的第一道关。
第二步 · 训练范式全链路预训练目标（Causal LM）→ SFT 数据构造 → RLHF（奖励模型 + PPO）→ DPO，能画出完整 pipeline 并讲清每步的数据流。
第三步 · 动手项目用 LoRA 微调一个 7B 模型（单卡可跑），做一个小型 RAG 系统（LangChain / LlamaIndex），再读 vLLM 的 PagedAttention 论文并写源码笔记。
第四步 · 论文追踪精读：Attention Is All You Need、GPT-3、InstructGPT、LoRA、DPO、DeepSeek-V3/R1 技术报告。面试时"读过 R1 报告并能复述 GRPO 训练流程"是强信号。

四、搜广推（搜索 / 广告 / 推荐）

岗位画像 岗位最多 · 变现最直接

工业界算法需求最旺盛的方向，字节 / 快手 / 美团 / 腾讯 / 阿里每家都有成建制的搜广推团队。技术栈高度一致，统称"信息流与检索"：召回 → 粗排 → 精排 → 重排的漏斗架构。2026 年的新趋势是大模型与搜广推融合——某北京公司搜广推 JD（50-70k·16薪）的职责已明确写为"负责大模型搜索增强核心算法研发与落地，内容推荐、流量分发"；虾皮 2027 校招"搜广推大模型方向算法工程师"则要求做"统一排序模型、Semantic ID、多模态表示学习"。

核心技能（JD 高频词）

召回（协同过滤 / 双塔 / 向量化 Embedding） 排序模型族（FM / DeepFM / Wide&Deep / DIN） CTR / CVR 预估 特征工程（大规模稀疏特征） SQL（Hive / Spark SQL，50% 时间在取数） A/B Testing 与显著性检验 多任务学习（MMoE / ESMM）序列建模（DIN / DIEN / SIM） 离线指标（AUC / GAUC / NDCG）图神经网络（PinSage） 强化学习（长期收益）LLM 语义 Embedding / 生成式推荐C++（性能敏感场景）

加分项：Kaggle / 天池 CTR 预测比赛名次；熟悉大厂技术博客（阿里 / 美团 / 字节团队博客代表国内最高水平）；理解业务侧逻辑——为什么搜索要相关性、广告要出价（eCPM）、推荐要多样性与惊喜感。

学习路径

第一阶段 · 基础（1~2 个月）统计与最优化 + Python + SQL 三件套；ML 基础模型（LR / GBDT）。SQL 一定练到能写多表 join + 窗口函数——"很多新人死在不会写复杂 SQL 取特征上"。
第二阶段 · 核心架构（1 个月）吃透漏斗：召回（CF / Item2Vec / 双塔）、粗排、精排（FM → Wide&Deep → DeepFM → DIN 演进脉络）、重排；每个模型能讲清"解决前一版什么问题"。
第三阶段 · 实战（1~2 个月）打一场 CTR 预测比赛；精读 Wide&Deep、DIN、MMoE、SIM 四篇论文并能白板复述结构。
第四阶段 · 前沿融合关注 LLM + RSA：生成式推荐、Semantic ID、大模型语义召回、冷启动应用——这是 2026 校招 JD 的新增高频考点。

五、AI Agent 方向

岗位画像 快速上升期

2026 年招聘市场上增长最快的方向，分两条线：Agent 算法（规划 / 记忆 / 工具调用 / 多智能体协作 / Agentic RL）与 Agent Infra / 工程（框架、评测、部署）。DeepSeek 招聘页单独设有 Agent Harness 团队和 Agent Infra 研发工程师岗位，并有"通用 Agent 数据产品经理（办公/生活/搜索）""Code Agent 数据工程师"等数据侧岗位；字节校招也有 Agent 算法岗位；美团校招 JD 出现了 Agentic RL 字样。这一方向懂工程的人比懂论文的人更稀缺，CS 科班 + 扎实工程能力是差异化优势。

核心技能（JD 高频词）

LLM 基础（能答透八股四大模型章） Prompt Engineering / 结构化输出 Function Calling / Tool Use / MCP Python 工程能力 Agent 框架（LangChain / LangGraph / 自研） 记忆系统（短期 / 长期 / 向量检索 RAG） 规划与反思（ReAct / Plan-and-Execute） 多智能体（Multi-Agent 协作） MCP / A2A 协议生态 Agent 评测（SWE-bench / 任务成功率 / 轨迹评估） 沙箱与安全Agentic RL（RL 训练 Agent）前后端全栈（应用岗）

加分项：自己从零搭过完整 Agent（而不是只调 API demo）、有开源 Agent 项目 star、在 SWE-bench / WebArena 等基准上做过实验、熟悉 DeepSeek-R1 式的推理强化学习并理解其与 Agent 决策的联系。

学习路径

第一步 · LLM 工程地基先把八股四大模型章答透，再动手：裸 API 实现 ReAct 循环（不依赖框架），理解 Agent = LLM + 工具 + 记忆 + 规划 的本质。
第二步 · 核心组件逐个击破Function Calling 的 JSON Schema 约束、RAG 全链路（切块 / Embedding / 检索 / 重排）、长期记忆设计、错误重试与自我反思机制。
第三步 · 完整项目做一个能跑真实任务的 Agent（如代码助手 / 信息搜集 / 自动化运维），重点是评测：任务成功率、平均步数、成本——面试官最想听你怎么量化效果。
第四步 · 进阶多智能体协作（AutoGen / MetaGPT 论文）、Agentic RL（读 DeepSeek-R1 报告 + 美团等团队的 Agentic RL 博客）、SWE-bench 复现。

七、求职准备时间线与行动建议

  • 投递策略：四大方向同投。大厂提前批（7~8 月）不笔试直接面试，是算法岗最重要的窗口；字节全年 4 次投递机会、内推优先，可尽早"试水"再迭代简历。
