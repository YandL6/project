📌 关于数据存储

所有数据保存在浏览器 localStorage 中，不会上传到任何服务器。数据按「题目」和「知识库」分开存储，迁移时分别导出导入。

方式一：GitHub Pages（推荐，免费）

📖 步骤说明
  1. 在 GitHub 创建仓库（如 leetcode-hot100）
  2. 上传 index.html、style.css、app.js 三个文件
  3. 进入 Settings → Pages，Source 设为 main 分支
  4. 访问 https://你的用户名.github.io/leetcode-hot100/

方式二：Vercel

📖 步骤说明
  1. 访问 vercel.com 用 GitHub 登录
  2. 点击 Add New → Project，导入仓库
  3. 部署后获得 .vercel.app 域名

方式三：Netlify（拖拽即部署）

📖 步骤说明
  1. 访问 app.netlify.com
  2. 将整个文件夹拖拽到 Sites 区域
  3. 自动部署完成
